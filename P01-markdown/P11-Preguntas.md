# Pregunta 1:
## Cuales son los principales tipos de SGBS

Diferenciamos principalmente tres tipos:

 Gestores de bases de datos ofimáticas: manipulan bases de datos pequeñas para almacenar datos de pequeñas empresas. 

 Gestores de bases de datos corporativas: gestionan bases de datos enormes, de medianas o grandes
empresas. Al manejar una cantidad de datos tan grande se requiere de un gran servidor

 Soluciones intermedias: Es un punto intermedio entre las dos anteriores citadas previamente. Un ejemplo puede ser My SQL.



# Pregunta 2

-Nivel físico: Hace referencia al hardware donde se almacenan los datos.

relaciones existen entre  ellos.
